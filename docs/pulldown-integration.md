# 高位下拉器械动画切片 · Draft PR

## 本阶段已实现（仅器械运动）
- `src/three/LatPulldownMachine.tsx`：程序化 Three.js/R3F 双柱龙门架、座椅、大腿固定垫、双滑轮、宽握杆、配重与钢索。无需额外资产下载，便于在当前仓库直接预览；今后可以用更精细的原创建模 GLB 替换。
- `src/three/pulldownMotion.ts`：同一归一化动作周期驱动横杆（向下 0.49 m）、配重块（向上 0.49 m）及绳索端点，支持当前播放器的暂停、循环、倍速和进度拖动。
- `src/data/latPulldown.ts`：基于 `catalogue` 实际元数据映射左右背阔肌、大圆肌、上臂屈肌、菱形肌和斜方肌的**定性参与角色**，使用真实 `anatomyId` 而非原型肌群 ID。
- 原有静态解剖模式、467 独立网格、双风格、IndexedDB、哑铃弯举关节原型保留。

## 重要边界
目前进入「动作实验室」点击「高位下拉」只显示**独立器械及其运动**，不显示会动的解剖人体。
现有 `public/models/anatomy.glb` 仍为 467 meshes / 0 skins / 0 animations。
**尚未完成**人体坐姿、统一比例标定、关节骨架、肌肉网格蒙皮、手-握杆 IK、肩胛运动和肌肉变形。这些功能不能因为器械运动通过就标记完成。

## 下一阶段 Blender 验证顺序
1. 在原始 GLB 的副本中保留完整源名称、467 唯一 `anatomyId`；测量人体与器械的尺度、骨盆及关节基准点。
2. 制作一个能坐下的肩-肘-腕单臂骨架和 5～10 个网格的受控权重试验，确认关节附近肌腱不会明显错位。
3. 在不破坏原始源模型的前提下扩展到双臂及上身，增加肩胛相关控制，IK 锁定器械抓握位置。
4. 导出真正具有 `skins > 0`、`animations > 0` 的 GLB，检查 0%、50%、100% 三个时刻抓握误差和穿模。
5. 真实动画接入后同时验证：运动中拾取独立肌肉、材质切换、单一时间轴、正/侧面效果和负载性能。

## 动作生理说明
热力颜色仅表示目标、协同、稳定等**定性类别**，不能将颜色或动画进度解释为实测 EMG、肌肉力量或增肌效果。

## 后续精修
