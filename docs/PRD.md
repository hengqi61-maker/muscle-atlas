# Muscle Atlas 产品需求

个人使用、本地优先、macOS 优先。中心是可交互人体，而不是商业健身平台。三栏：左侧结构与显示控制，中央共享 3D 场景，右侧结构/动作/训练详情，底部播放器。

## 使用目标
1. 根据日期查看计划目标肌群。
2. 根据实际完成组数回顾训练覆盖。
3. 用可解释历史辅助下一次安排。

## 边界
真实静态解剖、动画关节原型必须区别。人体网格可点击不证明有骨骼/蒙皮。Real Anatomy 当前仅材质与灯光风格，没有医学级纤维纹理。计划不能充当完成记录。原型关联是肌群级，不能冒充全部单块肌肉关联。

## 交付验收
首版：三栏可启动、轨道旋转/缩放/平移、真实网格可点击、风格切换、独立关节屈伸原型、播放/暂停/循环/速度/拖动、详情展示、持久化实录与导出。
后续：真实模型肘部两骨蒙皮小样及 GLB AnimationMixer 验证；自动聚焦、骨骼/深层/左右筛选；模板、日期计划与完成分离；实际组数热力图；只读 Calendar OAuth。

## 训练数据
AnatomicalMuscle / MuscleGroup / MuscleRegion / Exercise / ExerciseMuscleRelation / WorkoutTemplate / PlannedWorkout / WorkoutSession / CompletedSet。独立解剖身份优先 BP/FMA；肌群原型使用独立命名空间。热力图需说明时间范围、实际/计划、主要肌计完整组、其他角色计数方式；禁止输出未知刺激百分比。

## 非目标
注册、支付、多用户服务、临床诊断、自动人体负荷仿真、未经授权的日历写入。
