# 高位下拉运动建模审查与修正

颜色是动作参与角色，不是即时 EMG、肌肉力、训练量或刺激百分比。绿色为主要目标、黄色为协同、紫色为稳定与控制；蓝色仅表示选中。肌肉明显移动的幅度不能用来推断其受力。

## 原实现的问题

|问题|代码证据|修正|
|---|---|---|
|背肌被着色但静止|生成器仅对手臂、腿添加 Armature|背阔肌躯干端保留在躯干/腰部，上外侧附着区跟随肱骨|
|肩中心锁定|每帧直接使用固定 shoulder|增加胸廓、双侧肩胛带骨骼，动态肩中心驱动双臂 IK|
|肩胛肌附着缺失|菱形肌/斜方肌/大圆肌无骨骼权重|大圆肌连接肩带与肱骨，菱形肌/斜方肌在内侧躯干与外侧肩带之间混合|
|颜色语义混淆|选中与主要目标同为绿色|选中改蓝，角色说明常驻|
|验证只关心握点|缺少背肌变形与肩位测试|增加实际 Three.js 蒙皮顶点和肩中心的位移断言、背面/侧面截图|

比较过三条路线：单纯鼓包形态键不能修复起止点关系；肩带骨骼和附着区蒙皮可解释且可检测，当前采用；完整肌骨动力学需要个体标定、运动和负荷输入，留待研究扩展。没有新增替代手表面或重塑手指。

## 运动学与科学边界

肩胛骨会参与抬臂/下降，运动依赖负荷与任务，不能将一个固定比例当作所有人的规律。[加载与未加载肩运动的三维研究](https://pubmed.ncbi.nlm.nih.gov/33493783/)、[外部负荷与肩胛运动研究](https://pubmed.ncbi.nlm.nih.gov/38501436/)支持需要肩带联动，但并未提供本动画的数值标定。

当前参数是艺术与运动学示意：胸廓后倾6°；肩带额状面旋转从顶部15°至底部3°；肩带基点垂直位置从+10mm到−4mm，后向平移最多4mm。这不是受试者测量、标准动作处方或个体肩胛节律。权重依据空间附着区域平滑混合，没有真实肌腱材料、体积保持、碰撞或肌力求解。肩胛骨本身也不是已标定刚体解剖骨模型。

高位下拉牵涉背阔肌、肘屈肌以及肩带肌群，具体激活随动作与个体变化；EMG研究不支持把角色分类直接变成固定百分比。[握宽研究](https://pubmed.ncbi.nlm.nih.gov/24662157/)、[不同下拉变式研究](https://pubmed.ncbi.nlm.nih.gov/40981044/)。并非每块参与肌肉都应明显鼓起或位移；目前只修复运动附着关系，不伪造激活热力图。

## 可复现验收

`npm run test:pulldown` 在真实 GLTFLoader/AnimationMixer 中检查121帧：467个源网格、握点及轴向约束、骨骼无缩放、背阔肌上外侧与下部顶点区域的运动差异、肩中心位移。`docs/evidence/pulldown-runtime.json` 保存结果；这证明动画中有附着区联动，不证明解剖精度。

背面/侧面观察主动隐去遮挡人体的机架和配重，保留拉杆；全身视角显示完整器械。

浏览器流程覆盖动作切换、暂停/循环、背面0/1/2秒与侧面截图。仍需以后通过人工精修权重、局部形变与穿插测量改善腋下/肘窝，并用标定数据验证肩带轨迹。原始手部形状沿用源模型，未声称闭合抓握已解决。
